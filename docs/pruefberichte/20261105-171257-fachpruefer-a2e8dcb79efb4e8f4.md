# Bericht fachpruefer – 2026-11-05 17:12

🟡 Fast richtig, ein Halbsatz führt aber in die Irre. Ich habe nur gelesen, nichts ausgeführt: den Text, A47, A69 und A88 im Lastenheft, src/core/spiel.ts (ab Zeile 598, 727, 826) und src/core/freischaltung.ts:32. Dort steht wirklich „vorsehung: 4“, also stimmt „frei ab Heizzentrale Stufe 4“.
1. „Spart später die Anbohrung“ stimmt. Ein vorbereiteter Abzweig mit Kappe erspart, dass man die Leitung später anbohren oder auftrennen muss. Genau so rechnet auch das Spiel. Sicherheit 85. Die Fachwissen-Bibliothek (waermenetz.md) sagt zu Anbohrung, Abzweig und T-Stück nichts. Das ist eine Wissenslücke, mein Urteil beruht auf allgemeinem Fachwissen.
2. Befund (Sicherheit 80): „der Anschluss dockt selbst an“ klingt, als bräuchte ein echter Hausanschluss gar kein Abzweig-Teil. In echt hängt jeder Hausanschluss an einem Abzweig: an einem T-Stück, an einer Vorsehung oder an einer Anbohrung. Das Spiel setzt diesen Abzweig nur automatisch.
3. Vorschlag: „Für Hausanschlüsse nicht nötig – den Abzweig setzt das Spiel selbst. Ein T-Stück mit Vorsehung legt einen Abzweig für später bereit und spart dann das Anbohren. Frei ab Heizzentrale Stufe 4.“
4. Unsicher (Sicherheit 50): Laut A88 bleibt die Anbohrung vor der Freischaltung „kostenlos und unerwähnt“, der gesperrte Knopf erwähnt sie aber. Ob das mit A88 vereinbar ist, sollte der Projektleiter entscheiden. Vorgeschlagene Regel (Simon bestätigt): „Spieltexte zum automatischen Hausanschluss sagen ‚das Spiel setzt den Abzweig‘, nicht ‚kein Abzweig nötig‘.“
