## Kurzurteil
- **Genau eine Anschlussleitung je Haus:** Das entspricht der üblichen Praxis. Ein Gebäude bekommt seine Wärme über seinen eigenen Hausanschluss. Es zieht nicht nebenbei Wärme aus einer anderen Leitung, die zufällig am Haus vorbeiläuft. Diese Regel steht aber **nicht** als bestätigte Regel in der Bibliothek. Deshalb zählt sie als Annahme bzw. Spielregel (siehe Lücke L1 unten).
- **„Ist der Anschluss zu dünn, reicht die Leistung nicht“:** Das stimmt fachlich. Abhilfe ist in der Praxis ein dickerer Anschluss, kein zweiter Anschluss. Das Spiel behauptet hier nichts Falsches.
- **Vereinfachung „ganz kalt“:** In Wirklichkeit bekommt ein Haus an einem zu dünnen Anschluss nicht null Wärme. Es wird an kalten Tagen unterversorgt. Dass das Spiel daraus „kalt“ macht, ist eine zulässige Vereinfachung, solange kein Text behauptet, es komme gar keine Wärme an. Der heutige Text tut das nicht.
